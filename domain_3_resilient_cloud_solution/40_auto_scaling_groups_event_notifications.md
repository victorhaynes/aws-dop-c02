# ASG - SNS Notifications
- ASG supports SNS notifications on
`Launch`, `Launch Error`, `Terminate`, `Terminate Error`
- these are generic/the only ones out of the box

# ASG - EventBridge Events
- Can create EventBridge rules that match the following ASG events
- Launch Successful/Unsuccessful
- Terminate Successful/Unsuccessful
- ASG Instance REfresh Checkpoint Reached
- ASG Instance REfresh Started, Succeeded, Failed, Cancelled
