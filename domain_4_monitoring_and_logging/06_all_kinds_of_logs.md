# All Kinds of Logs
- I.e. Access Logs, OS Logs, Access Logs

Application Logs
- produced by app code itself, stack traces etc
- typically written to local file on file system
- usually streamed to CW logs using a CW Agent on EC2
- Lambda has direct integration with CW Logs
- If using ECS or fargte, direct integration with CW logs
- If using Elastic Beanstalk, direct integration with CW Logs

Operating System Logs (Event Logs, System Logs)
- generated by your OS (ec2 or on-prem)
- linux/windows etc, informs you of system behavior
- ex /var/log/messages or /var/log/auth.log
- Usually streamed to CW logs using a CW Agent

Access Logs
- lists all of the requests for individual files that people have requested from a website
- example for httpd: /var/log/apache/access.log
- Usually for load balancers, proxies, web servers, etc
- AWS provides some access logs for certain services


AWS managed logs
- Load balance access logs (ALB, NLB, CLB) -> to S3
- CouldTrail Logs ->  (all api calls) to S3 and CW Logs
- VPC Flow Logs -> S3 and CW Logs
- Route53 Access Logs -> to CW Logs
- S3 Access Logs -> to S3
- CF Access Logs -> to S3

`EXAM` the point is to understand the different categories/log generators
