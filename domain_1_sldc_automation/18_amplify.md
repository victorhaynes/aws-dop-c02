# AWS Amplify web and mobile applications

- A set of tools and services that helps you develop a deploy scalable full stack web and mobile applications

Lets say I want to make a backend
IT will use S3, cognito, AWS AppSync, API Gteway, SageMaker, Lex, Lambda, DynamodDB behind the scenes

Then we can make an Amplify frontend using frontend libraries
react, Vue, NEXT.js, iOS etc

Then using Amplify Console & deploy

`Amplify is the Elastic Beanstalk for Web Apps`

# Amplify Extras
- Connects to CodeCommit and have one deployment per branch in CodeCommit
- Connect your application to custom domain (Route53)
- i.e. dev.example.com branch
- example.com for production

1 deployment per branch `EXAM`
