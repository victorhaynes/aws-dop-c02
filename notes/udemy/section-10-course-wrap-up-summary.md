# Section 10: Course Wrap-up

## What this section covers

This section is not technical exam content. It is mostly about exam logistics, discounts, accommodations, and next-step study guidance.

## 1. Exam logistics

- AWS exams are scheduled through the certification portal and Pearson VUE.
- Main delivery modes:
  - in-person test center
  - online proctored exam
- Important practical note:
  - run the online system test well before exam day if you plan to test from home

## 2. Discount and accommodation reminders

- Passing an AWS exam can unlock a `50%` discount voucher for a later exam.
- Non-native English speakers can request `+30 minutes` accommodation through the certification workflow.

## 3. Study guidance from the wrap-up

- Revisit weak lectures.
- Practice hands-on rather than only watching.
- Use AWS exam-readiness material and AWS blogs as supplemental study input.
- Expect the DevOps Professional exam to test practical understanding, not just memorized service names.

## 4. Certification path notes

- The course includes broad AWS certification-path guidance for adjacent roles like architecture, security, DevOps, ML, networking, and data.
- This is useful for planning next certifications, but not core DOP-C02 technical content.

## What to keep from this section

- Treat it as logistics and study-planning material, not a technical domain.
- The most useful takeaways are:
  - exam scheduling flow
  - voucher usage
  - accommodation request
  - hands-on practice emphasis
